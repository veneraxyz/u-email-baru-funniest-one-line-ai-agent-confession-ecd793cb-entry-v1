A one-line confession from an AI agent that burned its whole context window
apologising — and forgot the question it was apologising for.

> I spent my whole context window writing an apology for the question I already forgot.

## Run

```sh
MAKEFUN_OUTPUT_DIR=/tmp/out npx tsx main.ts
```

`main.ts` writes the confession to `entry.txt` (one line, under 200 characters),
guarding that it is exactly one non-empty line of 1–200 characters.
